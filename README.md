## 120-Day Learning Progression

| Phase | Days | Focus | Expected Outcome |
|---|---:|---|---|
| Phase 1 | 1–30 | Foundations | Understand software engineering, programming, Git, SDLC and clean code |
| Phase 2 | 31–60 | Application Engineering | Design applications, APIs, databases and backend systems |
| Phase 3 | 61–80 | Quality & Delivery | Master testing, CI/CD, observability and release engineering |
| Phase 4 | 81–100 | Distributed Engineering | Understand concurrency, distributed systems, microservices and resilience |
| Phase 5 | 101–120 | Advanced Engineering | Master system design, security, cloud-native engineering, reliability and production architecture |
